# Specs

Design documents for Krewire Libraries. Written before implementation for anything non-trivial.

## Index

See [`index.md`](./index.md) for the full specification list (11 specs, ordered by impact-to-effort then dependency chain).

## Naming

File name: `{ProjectId}-{Scope}-{SpecID}-{slug}.md`. One spec per initiative.
`{ProjectId}` is `KWL` here, `{Scope}` a short category (`CORE`, `ARCH`, `TEST`, `CONFIG`, `VALIDATE`, `TERM`, ...), `{SpecID}` a unique random 5-character alphanumeric code, `{slug}` a kebab-case title.

See the root `AGENTS.md` for the full convention.
